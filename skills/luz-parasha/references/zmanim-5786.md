# זמני שבת — לוח תשפ"ו (משכן שלום)

Source of truth for the `luz-parasha` skill's זמנים. **הדלקת נרות = the big central "כניסת השבת" number** on the yearly luach; **צאת שבת = the big "יציאת השבת" number** (NOT the תל אביב / ירושלים strip values — verified against real bulletins). **מנחה = הדלקת נרות + 20 min, rounded to the nearest 5 minutes** (a judgement time, so confirm with the gabbai).

Match the upcoming parashah by name. Two-parashah weeks use the combined name (e.g. `מטות מסעי`). The `שבת` column is the special-Shabbat label for the heading (e.g. `שבת חזון`), empty if none; `מברכין` marks Shabbat Mevarchin (heading gets the מברכין prefix + a molad line — ask the gabbai for the molad).
